# Айжан, это важно ❗ (дружеский пранк)

Безобидная страница-шутка для одного человека. Ведёт через «срочную проверку»: убегающая капча,
фото-капча «выберите все квадраты, где вы красивая» (везде «ты»), «сканирование личности» со
зашкалившим уровнем крутости, льстивый опрос, вопрос с кнопкой «Нет», которую не поймать, — и финал:
**«Это пранк!»**, конфетти, генератор комплиментов и шуточный сертификат «самая классная».

- Одна HTML-страница, без сборки и без бэкенда. Хостинг — GitHub Pages.
- Звук на Web Audio (без файлов), разблокируется по первому касанию, можно выключить кнопкой.
  Уважается `prefers-reduced-motion`.
- Работает на телефоне и в десктопе. Ничего никуда не отправляет.
- В финале — **по желанию** «Селфи с сертификатом»: доступ к камере запрашивается явно, кадр
  собирается прямо в браузере и остаётся на устройстве; отправить его человек решает сам.

## Имя

По умолчанию — Айжан. Для другого человека добавьте `?name=Имя` к ссылке:

```
https://<логин>.github.io/aizhan/?name=Динара
```

## Проверить шаги

`?stage=1` — капча, `?stage=2` — сканирование, `?stage=3` — вопрос, `?stage=4` — финал.

## Локально

Просто откройте `index.html` в браузере.
