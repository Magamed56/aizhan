# Айжан, это важно ❗ (дружеский пранк)

Безобидная страница-шутка для одного человека. Ведёт через «срочную проверку»: капча, которая
убегает, «сканирование личности» со зашкалившим уровнем крутости, вопрос с кнопкой «Нет», которую
не поймать, — и финал: **«Это пранк!»**, конфетти и шуточный сертификат «самая классная».

- Одна HTML-страница, без сборки и без бэкенда. Хостинг — GitHub Pages.
- Звук на Web Audio (без файлов), можно выключить. Уважается `prefers-reduced-motion`.
- Работает на телефоне и в десктопе. Ничего никуда не отправляет; сертификат сохраняется/шарится
  самим человеком со своего устройства.

## Имя

По умолчанию — Айжан. Для другого человека добавьте `?name=Имя` к ссылке:

```
https://<логин>.github.io/aizhan/?name=Динара
```

## Проверить шаги

`?stage=1` — капча, `?stage=2` — сканирование, `?stage=3` — вопрос, `?stage=4` — финал.

## Локально

Просто откройте `index.html` в браузере.
